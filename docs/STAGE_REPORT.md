## 2. מה נבנה (קבצים)
`src/`: Config (סכמה מלאה, 46 טבלאות, בהן 5 פרטיות) · Util · Calc (ניווט, מסעות, Trap Bar, שקלול כש״ג, מבחנים A/B/C, פז״ם חלקי, ממוצעים, נוכחות) · Scoring (מנוע חיפוש טבלאות — חסום עד אישור) · Policy (מטריצת הרשאות) · Store (Sheets + נעילה) · AuthAudit · Records (יצירה / עריכת מנהל / ביטול / שחזור / בקשות תיקון / היסטוריה) · Courses (קורסים, ארגון 2×2, שכפול מבנה בלבד, ארכוב/פתיחה, משתמשים) · Navigation (מודול ניווט מלא בצד שרת) · Setup · Code (נקודת כניסה + רשימה לבנה של API) · Index.html (מסך זמני: בחירת קורס + הזנת ניווט).
`scoring/`: תמלול טיוטה של טבלאות כש״ג (JSON/CSV/XLSX + בדיקת רציפות) + 8 הצילומים.
`tests/`: 72 בדיקות אוטומטיות (`node tests/run.js`, `node tests/integration.js`).

## 3. מצב דרישות
