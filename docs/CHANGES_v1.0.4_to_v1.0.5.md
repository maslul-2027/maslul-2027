# שינויים מ-v1.0.4 ל-v1.0.5

בסיס: `ct_v1.0.4/` (נשמרת בחבילה v1.0.5 כנקודת השוואה, ללא שינוי, לצד `ct/` = v1.0.2 ו-`ct_v1.0.3/`). כל השינויים מתועדים כאן; **לא נמחקה ולא הוחלשה אף בדיקה קיימת** (343 בדיקות ה-Node ו-50 בדיקות הדפדפן של v1.0.4 רצות כמות שהן, שלוש הסוויטות הישנות לא שונו, ו-`ui_fitness` הורחבה בלבד).
