# בעיות פתוחות, החלטות ובדיקות Google — v1.0.6-b7b8-r2

## החלטות שדורשות אישור בעל המוצר
1. **"נפסלה"** — אין הגדרה מקצועית (אין סף עובר/נכשל; U6). לא יושם. אפשרויות: סף לרכיב / סף על ציון משוקלל / סימון ידני (שדה חדש + הרשאות) / בלי המושג.
2. **השלמה לפי התוצאה האחרונה בלבד** (לא צבירה בין תוצאות).
3. **out_of_range = "ממתין לבדיקה"**.
4. **רכיב שסוג המבחן אינו דורש = na** (נגזר מ-`weights_json`; גיבוי `components_json`). אושר כעקבי עם המימוש בניקוד.
5. **הסתרת תוצאות מבוטלות ממפקדים** — התנהגות קיימת, נשמרה.
6. מצב `blocked` (no_table / gender_missing / סיבה לא מוכרת / נתונים פגומים) מוצג כ"לא ניתן לנקד — נדרשת פעולת מנהל" — ניסוח לאישור.
