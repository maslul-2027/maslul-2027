# אסטרטגיית גיבוי ושחזור — שרת TEST סינתטי (Cloudflare Free + D1)

**סטטוס כנה: `NO-BACKUP` (לא נתמך ולא מאומת).** שום דבר במסמך הזה לא מוכח על המארח. עד שיוכח — נתוני ה-TEST הם **חד-פעמיים (disposable)**.

## מה כן ומה לא
| נושא | מצב | הערה |
|---|---|---|
| קביעות הנתונים ב-D1 (קריאה אחרי כתיבה, סשן שני) | מוכח בסנדבוקס מקומי (Worker אמיתי + D1 shim; בענן: workerd + D1 מקומי) | לא הוכח על D1 מרוחק |
| `backup.create / restore / recover` | **NOT_CONNECTED** בענן (אין אחסון קבצים ב-Free) | הממשק מציג שגיאה כנה, לא הצלחה מזויפת |
| `reports.fullExport` | NOT_CONNECTED | PDF/XLSX המצרפיים בדפדפן **אינם** ייצוא נתונים מלא ואינם גיבוי |
| שחזור לנקודת זמן (D1 Time Travel) | **לא מאומת** | תכונה של Cloudflare; דורשת הרשאות חשבון — לא נוסתה |

## תכנית מוצעת (לא ממומשת, דורשת אישור ואסימון מהבעלים)
1. **ייצוא**: workflow ידני `workflow_dispatch` שמריץ `wrangler d1 export <db> --remote` עם אסימון API **בהיקף D1 בלבד** שהבעלים מגדיר כ-Secret ב-GitHub Environment (Claude לא יוצר ולא רואה אותו).
2. **הצפנה ושמירה**: הקובץ מוצפן (age/gpg עם מפתח ציבורי של הבעלים) ונשמר כ-artifact פרטי עם שמירה קצרה; לא נשמר בריפו.
3. **שחזור מאומת**: workflow נפרד יוצר מסד **זמני חדש** (`maslul-test-restore-<run>`), מייבא אליו, מריץ `scripts/cf_ci_smoke.js` + בדיקת ספירות/ה-SHA של טבלאות, ומוחק את הזמני. **לעולם לא** שחזור על המסד המתארח.
4. עד לאימות כל השלבים: סטטוס נשאר NO-BACKUP.

## מדיניות עד אז
- נתונים סינתטיים בלבד; אובדן המסד הוא תוצאה מקובלת (טעינה מחדש בלחיצה על "טעינת קורס סינתטי").
- אין נתונים אמיתיים. אין הסקה ש"D1 = גיבוי".
- שחזור קוד/אפליקציה: פריסה מחדש של SHA קודם דרך workflow הפריסה (אישור ידני של הבעלים ב-Environment) או `wrangler rollback` על ידי הבעלים.
