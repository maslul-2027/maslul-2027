# MASLUL 2027 — native app status (branch `claude/native-shell`)

Look & feel: the original PR #10 shell (tokens, hero, KPI cards, 4 tabs **בית / חניכים / מעקבים / עוד**), no iframe, no legacy header/side/tab bars.
One data/logic layer: `window.appClient.api(method,args)` → the real `src/*.gs` server code running in the page over a synthetic store (`preview/engine.js`, generated by `scripts/build_native_app.js`). The UI holds no data of its own.
Synthetic only: 60 invented trainees, no network, no real data. Real-use blockers are listed separately in `docs/GOOGLE_TEST_VERIFICATION_REQUIRED.md` and the PR description.
