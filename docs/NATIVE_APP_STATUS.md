## QA gate for PR #53 (response to ChatGPT's blocking comment)
New `scripts/e2e_native_qa.js` (15 checks, in CI + `ui_synthetic_app`; screenshots in `docs/qa_screens/`, 320/360/390/414 × 8 screens + record sheet):
- **Responsive/RTL/a11y** at 320/360/390/414 on home, more, summaries, fitness admin, qualifications, marches, attendance, corrections and the record-sheet dialog: `dir=rtl lang=he`, no horizontal overflow, no element past the right edge, targets ≥44px, every field has an accessible name, dialog labelled + focus inside + Escape closes; keyboard Tab reaches all four tabs with a visible focus ring, Enter activates.
- **Attendance**: new roll dialog (`attendance.roll`) on each event; create (absent + early exit) → list/roll/summary read-after-write, survive reload; concurrent double submit with the same request_id = one event; `attendance.roll` on a foreign course denied.
- **Records**: edit/cancel/restore persist after reload; editing a cancelled record → RECORD_CANCELLED; history has ≥4 entries; duplicate request_id returns the same record; UI triple-click creates exactly one.
- **Stale writes**: `assignments.setActive` with an old `expected_updated_at` → CONFLICT and the first write is kept. *Gap (honest):* `record.edit` and `followups.update` have no optimistic-concurrency parameter in the server contract, so no stale test exists for them.
- **Fitness contract**: draft never scores (`no_table`); bare-number time, negative and fractional reps rejected; approve needs `verified_against_source:true` + reason; approved scores deterministic and monotonic (faster run ≥ score); record keeps the version it was scored with; partial components never produce a weighted score; approved version immutable; a second approval supersedes the first (exactly one APPROVED); weights must sum to exactly 100, unknown components/negatives refused, reason required; commander gets FORBIDDEN for weights/import/typeCreate. *Gap (honest):* exact score values are not compared to the source images — that needs the owner's professional confirmation of the transcribed tables (the version stays "verified in demo only").
- **Isolation**: commander gets no OK on 7 read/write routes of a course outside their scope.
- **Small groups**: a 3-soldier course returns only `{suppressed, small_group, reason}` for attendance and fitness summaries (no figures); with 6 soldiers figures are shown.
Bugs found and fixed by this gate: fitness-admin overflow at every width (long unbroken text in `dl.kv`), preview-engine id counter restarting after reload (could reuse `id-N` and collide).
